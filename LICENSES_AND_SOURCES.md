# Kaynaklar ve lisanslar

## Kur'an metni
Tanzil Project — https://tanzil.net/
Lisans ve kullanım şartları: https://tanzil.net/docs/Text_License
Tanzil metni değiştirilmeden kullanılmalı; kaynak bildirimi ve tanzil.net bağlantısı korunmalıdır.

## API
AlQuran Cloud API — https://alquran.cloud/api
Arapça sayfa metni ve `tr.diyanet` meal edition'ı ağ üzerinden alınır. Bu projeye meal metni gömülmemiştir. Çevirinin dağıtım/yeniden kullanım şartları için ilgili hak sahibinin koşulları geçerlidir.

## Ses
Ses akışı AlQuran Cloud CDN üzerinden `ar.alafasy` okuyuşu olarak istenir. Ses dosyaları bu ZIP'e dahil edilmemiştir. Dağıtım veya toplu çevrimdışı paketleme öncesinde ilgili kaynağın şartları ayrıca kontrol edilmelidir.
